# Coregix

Coregix jointly aligns overlapping georeferenced rasters using global transforms and local deformation meshes. Fixed reference rasters can anchor the alignment.

See [Alignment](usage/alignment.md) for Python and CLI examples, [Concepts](concepts.md) for the models, and [API Reference](api/alignment.md) for all options. Standalone [edge trimming](usage/edge-trimming.md) remains available after alignment.
